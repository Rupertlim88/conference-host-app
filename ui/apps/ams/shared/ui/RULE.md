# The UI's building blocks are shadcn/ui components, kept as shadcn makes them.

The shadcn/ui components this UI uses, as the shadcn command writes them for the base-nova style set in the app's `components.json`, and `utils.ts`, which hands shadcn's own `cn` to every file that merges class names. Add a component with `npx shadcn@latest add <name> -c ui/apps/ams`.
